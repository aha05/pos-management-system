# POS Management System

A full-stack Point of Sale (POS) Management System built with **Spring Boot microservices** and **React, TypeScript, and Tailwind CSS**. The system aims to streamline merchant operations, POS terminal management, transaction processing, settlement account management, and reporting.

## Tech Stack

**Backend:** Java, Spring Boot, Spring Cloud, REST APIs, Apache Kafka, Docker

**Frontend:** React, TypeScript, Tailwind CSS, Vite

**Infrastructure:** Spring Cloud Config Server, API Gateway

## Key Features

- Merchant and business profile management
- Branch management
- POS terminal management and assignment
- Settlement account management
- Transaction management
- Reporting and transaction insights
- Microservice-based architecture

## Project Structure

```text
pos-management-system/
├── backend/    # Spring Boot microservices
└── frontend/   # React + TypeScript application
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/aha05/pos-management-system.git
cd pos-management-system
```

Configure the required environment variables and infrastructure, then start the backend microservices and frontend application.
